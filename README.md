# my first project
## 1.1商品计价与输出
- 输入商品条码，可以显示这个商品的名称与价格，同时支持多个商品条码的同时输入
- 输入prices指令时，可以查看所有商品的信息

## 1.2订单结账
- <id> 输入条码，记录对应商品+1，显示价格
- <id> 在输入前添加一个减号，记录对应商品-1
- print 打印现在的小票，包含商品种类、数量与价格，以及小计价格
- drop 清空记录，重新开始
- checkout 结账，打印小票并清空记录。

## 1.3当日销售统计
- 每次checkout后，将本次交易记录（包括流水号、时间、商品信息、总价）追加写入文件
- 提供命令 sales [day] 查看当日所有销售记录及总营业额
- newday 开启新的一天，清空当日销售记录，保留文件中历史记录

## 2.1新增管理员模式
- admin ：进入管理员模式，需输入密码admin123
- setprice <条码> <名称> <新价格> ：修改指定商品价格
- itemadd <条码> <名称> <价格>: 添加一个新商品
- itemdel <条码> : 删除一个商品
- back : 推出管理员模式
